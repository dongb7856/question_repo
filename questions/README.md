## 说明

- PDF 文件可直接打开查看；HTML 为原始页面，同目录下有提取出的 `.txt` 纯文本（爱真题来源的 `.txt` 质量较好）。
- **政治 2021**：建议优先看 PDF（环球网校）；网页版 `.txt` 提取不完整。
- **民法 2025**：公开资源为 **3 张 PNG 截图**，已单独下载，后续需 OCR。
- 2025 年民法目前公开资源较少，本次使用广东成考网回忆版。
- 爱真题打包下载需付费，故采用其免费网页版 + 环球网校公开 PDF。
- 重新下载可运行：`python3 scripts/download_questions.py`
