2025成人高考专升本《政治》选择题（河南成考网·考生回忆版）

选择题
1.恩格斯在相关论述中明确指出，马克思的整个世界观不是教义，而是( )
（A）现成的结论
（B）研究问题的方法
（C）永恒不变的真理
（D）改造世界的工具
【正确答案】B

2.马克思主义认为，物质是标志客观实在的哲学范畴，下列不属于物质范畴的是( )
（A）暗物
（B）反物
（C）人工智能
（D）人类智能
【正确答案】D

3.20世纪70年代，毛泽东提出了划分“三个世界”的战略思想。在这一划分中，第三世界属于( )
（A）苏美
（B）苏美以外的西方发达国家
（C）东欧
（D）亚、非、拉丁美广大发展中国家
【正确答案】D

4.唯物辩证法除了否定之否定对立统一，还有( )
（A）矛盾对立
（B）普遍联系规律
（C）量变质变规律
（D）现象表现本质规律
【正确答案】C

5.恩格斯批评“费尔巴哈打破了黑格尔的体系，但简单地宣布一种哲学”是错误的。恩格斯的这一论述体现了( )
（A）超前思维
（B）逆向思维
（C）发散思维
（D）辩证思维
【正确答案】D

6.蜜蜂建筑房屋的本领让工匠自愧，但是人类建造的房屋远比蜜蜂建造的结实，在建造前在自己大脑就有了一个画面。马克思的这一理论强调人的实践活动( )
（A）感性的直接的活动
（B）有目的、有意识的
（C）客观的物质的
（D）批判的革命的
【正确答案】B

7.习近平指出，了解情况的渠道千条万条，但是要把调查研究放在第一条。这一论述体现的哲学道理是( )
（A）直接经验是获得知识的唯一渠道
（B）直接经验完全排斥问接经验
（C）一切真知都是从直接经验发源
（D）一切事物都必须去直接经验
【正确答案】B

8.马克思主义唯物史观认为，社会存在决定社会意识。社会存在是指社会物质生活条件，是社会生活的物质方面，它不包括以下哪些方面( )
（A）自然地理环境
（B）人口因素
（C）物质生产方式
（D）历史文化传统
【正确答案】C

9.普遍交往是世界历史的基本特征，这是(A)提出的观点。( )

（B）列宁
（C）斯大林
（D）毛泽东

10.马克思指出，“手推磨产生的是封建主的社会，蒸汽磨产生的是工业资本家的社会”,这一论述的基本原理是( )
（A）生产关系反作用于生产力
（B）生产力决定生产关系
（C）经济基础决定上层建筑
（D）上层建筑反作用于经济基础
【正确答案】B

11.一个政党的纲领，是公开树立起来的一面旗帜。在新民主主义的经济纲领中，标明新民主主义革命的主要内容是( )
（A）没收官僚资本归新民主主义国家所有
（B）没收封建地主阶级的土地归农民所有
（C）保护民族工商业
（D）实行耕者有其田的土地制度
【正确答案】B

12.党领导新民主主义革命的过程中，把党的建设作为一项“伟大的工程”,其中形成的三大优良作风，分别是( )
（A）理论联系实际、密切联系群众、批评与自我批评

（C）独立自主、自力更生、实事求是

【正确答案】A
